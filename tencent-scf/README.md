## 一、准备密钥

### 1. DeepSeek API Key（必需，~¥10/月）
- https://platform.deepseek.com → 注册 → API Keys → 复制 `sk-xxx`
- 充值 10 元够用 1-2 个月

### 2. Tavily Search API Key（必需，免费）
- https://app.tavily.com → 注册 → 复制 `tvly-xxx`
- 免费额度每月 1000 次搜索

### 3. QQ 邮箱 SMTP 授权码（可选，用于收邮件）
- QQ邮箱 → 设置 → 账户 → 开启 SMTP → 获取授权码

## 二、部署步骤（5 分钟）

### 步骤 1：注册腾讯云

1. 打开 https://cloud.tencent.com
2. 用微信扫码登录（学生认证后有更多免费额度）
3. 搜索「云函数 SCF」进入控制台

### 步骤 2：创建函数

1. 点击「新建」→ 选择「从头创建」
2. 填写：
   - **函数名称**：`daily-briefing`
   - **运行环境**：Python 3.9
   - **函数代码**：选择「在线编辑」
   - 把 `index.py` 的全部内容粘贴进去
3. 高级配置：
   - **执行超时时间**：改为 **300 秒**（默认 3 秒太短）
   - **内存**：128 MB（够用）
4. 点击「完成」

### 步骤 3：配置依赖层

SCF 默认没有 requests 和 openai 库，需要添加依赖层：

**方法 A（推荐）：在函数配置中添加**
1. 函数详情 → 「层管理」→「添加层」
2. 选择「自定义层」→「新建层」
3. 层名称：`briefing-deps`
4. 运行环境：Python 3.9
5. 上传方式：本地上传 zip
6. **创建 zip 包**：
   ```bash
   # 在本地执行（有 pip 的环境）
   mkdir layer && cd layer
   pip install requests openai -t .
   # 把 layer 目录打包成 zip
   ```
7. 上传 zip → 完成

**方法 B（更简单）：使用在线依赖**
1. 函数详情 → 「函数代码」
2. 在代码最前面加一行安装逻辑（见下方代码修改）

> **最简方案**：如果不想折腾依赖层，我已经在代码中内置了自动安装逻辑，见下方。

### 步骤 4：配置环境变量

1. 函数详情 → 「函数配置」→「环境变量」
2. 添加以下变量：

| 键 | 值 |
|---|---|
| `DEEPSEEK_API_KEY` | sk-你的密钥 |
| `TAVILY_API_KEY` | tvly-你的密钥 |
| `EMAIL_SENDER` | 你的QQ号@qq.com |
| `EMAIL_PASSWORD` | SMTP授权码 |
| `EMAIL_RECEIVER` | 接收邮箱 |

### 步骤 5：设置定时触发器

1. 函数详情 → 「触发管理」→「创建触发器」
2. 填写：
   - **触发方式**：定时触发
   - **触发周期**：自定义触发周期
   - **Cron 表达式**：`0 8 * * * * *`（每天北京时间 08:00）
3. 点击「提交」

## 常见问题

**Q: 函数超时了？**
- 检查执行超时时间是否改为 300 秒
- DeepSeek API 偶尔慢，可以改为 600 秒

**Q: 依赖安装失败？**
- 使用方法 A 的依赖层方式，手动打包上传

**Q: 没收到邮件？**
- 检查 EMAIL_PASSWORD 是否为 SMTP 授权码（非 QQ 密码）
- 查看垃圾邮件

**Q: 想改运行时间？**
- Cron 格式：`秒 分 时 日 月 星期`
- 每天早上 7:30 → `0 30 7 * * * *`
- 每天早上 9:00 → `0 0 9 * * * *`
